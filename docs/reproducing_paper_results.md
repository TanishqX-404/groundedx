# Reproducing Paper Results

The manuscript reports the results below on the full 600-window test split,
averaged over three evaluation seeds. The existing `results/` files were
generated by an earlier prototype path and should not be treated as a byte-for-
byte reproduction of these numbers until the released model files, dataset,
and harness are attached.

| Method | Top-1 | Macro-F1 | Faithfulness | Latency | VRAM |
| --- | ---: | ---: | ---: | ---: | ---: |
| Rule-based | 0.332 +/- 0.004 | 0.356 +/- 0.003 | - | - | - |
| RandomForest | 0.571 +/- 0.003 | 0.599 +/- 0.004 | - | - | - |
| Zero-shot SLM, 3B-Q4 | 0.520 +/- 0.003 | 0.480 +/- 0.004 | 0.00 | 680 ms | 2.1 GB |
| RAG SLM, 3B-Q4 | 0.700 +/- 0.003 | 0.670 +/- 0.004 | 0.75 | 1,150 ms | 2.3 GB |

Target hardware: NVIDIA RTX 3050 laptop GPU with 4 GB VRAM and 16 GB system
RAM. The full dataset is 4,000 windows split 2,800/600/600; the default KB is
128 historical cases, eight per class.

For the CPU path from a clean checkout:

```powershell
python -m pip install -e ".[dev]"
python simulator.py --n 4000 --seed 7
python kb_builder.py --build --cases-per-class 8
python baselines.py
python evaluate.py
```

The optional local-model path requires separately licensed GGUF weights and
`llama-cpp-python`:

```powershell
python run_llm_eval.py --model models\qwen2.5-1.5b-instruct-q4_k_m.gguf --limit 50 --mode both
python profile_runs.py --limit 25 --model models\qwen2.5-3b-instruct-q4_k_m.gguf
```

The intended release harness will run the configured seeds `[7, 19, 41]` and
report mean +/- standard deviation for accuracy and macro-F1. GPU latency,
VRAM, and power can vary substantially with GPU, driver, CUDA, llama.cpp, and
model-build versions. Treat values within normal run-to-run variation as
consistent rather than expecting bitwise-identical results.

The paper's eight-way sweep is 1.5B/3B x Q4/Q8 x zero-shot/RAG. Reported
RAG latencies range from 650 ms (1.5B-Q4) to 1,550 ms (3B-Q8). Profiling and
power are averaged over a single 25-call pass per configuration, and six
configuration accuracies are estimated from that small harness. These are
deliberately documented limitations rather than hidden claims.
